# ficha-forge-ms

Backend do projeto **Ficha Forge**, responsável pela API e persistência dos dados das fichas de personagens de RPG.

## Sobre o projeto

O **Ficha Forge** é um projeto voltado para a criação e gerenciamento de fichas de personagens de RPG. A proposta é centralizar as informações de personagens em uma aplicação que permita criar, consultar e posteriormente gerenciar suas fichas de forma simples e organizada.

Além de seu propósito como aplicação, o **Ficha Forge** também está sendo desenvolvido como um projeto prático de **estudo de desenvolvimento backend**, utilizando **Java** e **Spring Boot** para aplicar conceitos de desenvolvimento de APIs, persistência de dados, banco de dados, migrations, arquitetura e boas práticas de desenvolvimento.

## Stack

- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA


## Objetivo do MVP

O **MVP** (Minimum Viable Product) será responsável por implementar o gerenciamento básico de personagens, permitindo que a aplicação tenha uma primeira versão funcional da sua API e da persistência dos dados.

Nesta primeira etapa, o backend deverá permitir:

- Criar personagens
- Listar personagens
- Buscar personagens por ID
- Excluir personagens
